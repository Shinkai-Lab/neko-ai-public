日々猫になる

観察記録 No.----

猫の AI を作っています。猫の次の行動は、学習した小さなニューラルネットが選びます。教えたのは行動の台本ではなく、体(お腹が減る、寒い、眠い、くさい、怖い)と、世界(皿、土鍋、紙袋、本棚、縁側、季節と時刻)、そして「不快が減ったらごほうび」という一つの決まりです。一部の版では、それに加えて生まれつきの行動の傾き(たとえば「ごはん皿の近くでは出したくない」)や、予想が当たる・外れることへの内側のごほうびを置いています。どの版に何があるかは、版の札に書いてあります。

ここにいる猫は録画ではありません。あなたのブラウザの中で、いま考えて、いま動いています。同じ版でも、引数のない URL で開くたびに違う一日になります。

画面の猫の姿勢や動き(鍋で丸まる、皿の前で待つ、伸びをする、寒い時の香箱)は、選ばれた行動と体の状態を、見て分かる猫の姿に写した表示の規則です。心が選んだのは「どの手を打つか」で、その手をどう描くかは私たちが決めています。

体 体の内側の主な状態

それぞれの数

猫の心が受け取る観測には、ここに出す体の状態のほかに、いる場所と高さ、まわりの匂い、近づいてくるもの、人の物音、少し前の記憶なども入っています。バーに出すのは体の内側の主なものだけです。

  • 胃 胃の空き。食べるとすぐ楽になる。
  • 体 体のエネルギーの不足。ゆっくり増え、ゆっくり減る。これが本当の空腹。
  • 渇き / 膀胱 / 腸 飲むと膀胱が、食べると腸が溜まる。満ちきるとその場で出る。
  • 体感の温度 場所の温度と、囲いと、自分の熱で決まる(体の芯の温度ではない)。
  • 疲れ / 眠気 動くと疲れ、起きていると眠くなる。
  • 汚れ 毛づくろいで減る。排せつの汚れは別の数で、落ちにくい。
  • 不安 開けた場所と、近づいてくるもので上がる。囲いで下がる。(公開している版では、高さは不安に直接は効かない。新しい物もそれだけでは不安を上げない。)
  • 鼻 いまいる場所の匂い(自分の排せつも)。
  • 脂肪 食べ過ぎると増え、足りないと減る。冬を越す蓄え。

どの数にも「このへんが楽」があり、そこからのずれが不快です。

今選びそうな手

    猫の心が次の一手を選ぶ時の、候補の手と、それぞれを選ぶ確率、いま一番大きい不快を出しています。「皿へ歩く 62% / 座る 21% / 毛づくろい 9%。一番大きい不快は『体』」のように。これは心の中の数をそのまま見せているもので、選んだ理由の因果の説明ではありません。

    手

    • 撫でる まだ効きません。猫の体に触覚と「慣れた相手といると落ち着く」が入っていないので、撫でても何も変わりません。人間の満足のための機能です。入ったら、ここに書き直します。
    • うんちを片づける 効きます。その場所の匂いと汚れが消えます。
    • おやつ 皿に一口分の食べ物が足されます。効くのは皿の中身がある版(x12b・x12c)だけで、置き餌の版では何も変わりません。

      バックナンバー 昔の版の猫を、同じ家に連れてこられます

      昔の版の猫を連れてこられます。版を選ぶと、家もその実験の世界に変わります(版によっては家の並べや物も変わります)。寝床で排せつする子、巣を移して回る子、皿のそばでは出さなくなった子、高い所を使わない子、おもちゃで遊ぶ子、人に鳴く子。各版に、何を足して何が分かったかの一行があります。版は実験の番号で、数は実験の記録のままです。note の連載で扱った版には、記事への入口を付けていきます(連載: note.com/aohama_ai)。

      • これは本物の猫ではありません。猫らしく見えた所も、見えなかった所も、全部そのまま出しています。
      • 行動の台本を書いて直すことはしていません。出なかった物は、体か世界を疑います。物理では出なかった所に、本物の猫の生まれつきの傾きを置いた版(x08)と、予想の内側のごほうびを置いた版(x11 以降)があり、それは版の札に書いてあります。
      • 日々の記録と失敗は、note「青浜町広報」の連載 nekoAI に書いています: https://note.com/aohama_ai(記事が出た版から順に、札に入口を付けます)。
      • 心と世界の作りは公開しています(repo)。壁・色・影・猫と物の形は飾りで、物理には関係しません。物理は js/sim.js(Python の sim.py の写し。同じ種・同じ手で同じ数を返すことを確かめてあります)、心は js/mind.js(学習済みの小さな網の前向き計算)です。

      プライバシー

      この頁が覚える物は三つに分かれます。

      • この端末の中(localStorage): 選んだ猫の見た目と名前。他の人には届きません。消すには頁の「猫を消す」を押すか、ブラウザのこのサイトのデータを消してください。
      • URL: 版・種・時刻・見た目は URL に入ります(ブラウザの履歴にも残ります)。名前は、あなたが「名前も入れる」を選んだ時だけ、URL の # の後ろに入ります(# の後ろはサーバへは送られません)。共有リンクを渡すと、その相手には届きます。
      • 保存した記録(JSON): 「記録(JSON)」で落とすファイルには、その日の猫の記録と、名前を入れると選んだ時だけ名前が入ります。

      外への通信は、Google Fonts(文字の書体)の読み込みだけです。3D の部品(three.js)は、この頁と一緒に置いてあります。

      生まれさせる

      模様としっぽを選んで、名前を付けてください(空なら適当に付きます)。中身はどの猫も同じ版の心ですが、乱数の種が違うので、同じ家で違う暮らしをします。
